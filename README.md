# KPI Schedule Telegram Bot
### Асинхронний Telegram-бот на Python для перегляду розкладу занять КПІ ім. Ігоря Сікорського.
Бот інтегрований із Campus KPI API, підтримує збереження обраної групи, форматування часу без секунд, відображення викладачів та можливість додавати власні Zoom/Meet посилання для всієї групи.
## Стек технологій
<br> Мова програмування: Python 3.12 </br> 
<br> Фреймворк: aiogram 3.x (Async Telegram Bot API) </br> 
<br> База даних: SQLite3 (збереження вибору користувачів та Zoom-посилань) </br> 
<br> API: Campus KPI Schedule API </br> 
<br> Форматування: HTML-парсер з обробкою спецсимволів (html.quote) та Regex для очищення формату часу </br> 
##  Основні можливості
Актуальний розклад: Автоматичне завантаження пар із сервера КПІ з виведенням часу, теми та викладача.  

Кастомні Zoom/Meet посилання: Збереження та відображення посилань на онлайн-лекції для конкретних предметів вашої групи.  

Персоналізація: Запам'ятовування Telegram ID та прив'язаної групи у базі даних (не потрібно вводити ID кожного разу).  

Зручний UX: Інтерактивна клавіатура (ReplyKeyboardMarkup) для швидкого навігування та системне меню команд (BotCommand).  

Чистий вивід: Форматування часу без секунд (10:25 замість 10:25:00).

##  Встановлення та запуск 
### 1. Клонувати репозиторій
```bash
git clone https://github.com/your-username/kpi-schedule-bot.git
cd kpi-schedule-bot
```
### 2. Налаштувати віртуальне оточення
```bash
python -m venv venv
```

Для Linux / macOS:
```bash
source venv/bin/activate
```
Для Windows:
```bash
venv\Scripts\activate
```
### 3. Встановити залежності
```bash
pip install -r requirements.txt
```
### 4. Додати токен бота
У файлі main.py вкажіть ваш BOT_TOKEN, отриманий від @BotFather : 
```Python
BOT_TOKEN = "ВАШ_ТЕЛЕГРАМ_ТОКЕН"
```
### 5. Запустити бота
```bash
python main.py
```
##  Доступні команди та меню
| Команда | Опис |
| :--- | :--- | 
| /start | Запустити бота та відкрити головне меню з кнопками| 
| /setgroup [ID] | Встановити або змінити ID вашої групи (наприклад,/setgroup 3970) |
| /today | Отримати розклад пар на поточний тиждень |
| /addzoom [Предмет] [Посиланя] | Додати Zoom/Meet посилання для своєї групи |
##  Схема бази даних
#### Бот автоматично створює та ініціалізує файл bot_database.db з наступними таблицями:

user_groups: user_id (PRIMARY KEY), group_id

zoom_links: id (PRIMARY KEY), group_id, subject_name, link
